# Security Policy

## Supported Versions

Only the latest commit on `main` is supported. Fixes are not backported to
older tags.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues, pull requests
or discussions.

Instead, report them privately through GitHub: go to the **Security** tab of
this repository and choose **Report a vulnerability**. Include a description of
the issue, the affected code or configuration, and steps to reproduce it if
you can.

gofix is a fork of QuickFIX/Go intended primarily for internal use within
Appital. We will look at every report, but we respond on a best-effort basis
and cannot commit to a response or fix time.

If the vulnerability is also present in upstream
[QuickFIX/Go](https://github.com/quickfixgo/quickfix), please report it to that
project as well.
